# 🖥️ SARRS - NGO Dashboard

The NGO Dashboard is a web-based interface of the **SARRS (Street Animal Rescue & Reporting System)** that allows NGOs and authorities to manage reported animal cases efficiently.

---

## 🚀 Features

- 🔐 Secure login for NGO/authority access  
- 📋 View all reported cases  
- 🔍 Access detailed report information (location, images, description)  
- 👤 Assign and view volunteers for each case  
- 📌 Claim and manage assigned cases  
- 📊 Update report status (Pending → Claimed → Resolved)  
- 📤 Upload resolution proof before marking a case as resolved  
- 🔔 Receive real-time updates for new reports  
- 🧾 Maintain case handling transparency
